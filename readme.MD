# Kalkulator Sederhana Java
Ini adalah project Kalkulator sederhana untuk modul 3 bagian praktik.

## Fitur
* **Penjumlahan** (`tambah`)
* **Pengurangan** (`kurang`)
* **Perkalian** (`kali`)
* **Pembagian** (`bagi`)
* **Penanganan Error**: Secara otomatis menangani dan memberi tahu pengguna jika terjadi pembagian dengan nol.

## File Kode
Proyek ini terdiri dari dua file utama:

### 1\. Kalkulator.java

Ini adalah *class* utama yang berisi semua logika untuk operasi matematika.

### 2\. Main.java

Ini adalah *class* yang berisi method `main` untuk menjalankan dan menguji `Kalkulator`.

## Cara Menjalankan

1. Pastikan Anda memiliki **Java Development Kit (JDK)** terinstal di komputer Anda.
2. Buka terminal atau command prompt dan navigasikan ke direktori tersebut.
3. Compile semua file Java:
    ```bash
    javac Kalkulator.java Main.java
    ```
5.  Jalankan program:
    ```bash
    java Main
    ```
